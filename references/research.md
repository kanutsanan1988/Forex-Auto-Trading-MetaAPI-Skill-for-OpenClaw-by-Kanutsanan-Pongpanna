# Research — ทำวิจัยต่อยอด

## 1) คลังงานวิจัยที่ให้มาทั้งหมด

`trading-system/research/` เก็บ **ทุกไฟล์ ทุกช่วงเวลา** ของงานวิจัยเดิม รวมถึง
ประวัติการพัฒนา บันทึกการทดลอง แผนงาน แบบจำลอง และผลทดสอบที่ล้มเหลว

**จุดเริ่มอ่าน:**

| ไฟล์ | อ่านเพื่อ |

| `research/README.md` | ภาพรวมคลัง |

| `research/collaboration-history.md` | ประวัติการร่วมงาน/การตัดสินใจ |
| `research/consolidated-research-log.md` | บันทึกวิจัยรวม (ใหญ่สุด) |

## 2) วิธีทำงานวิจัยกับ AI (ทำตามนี้)

1. **อ่านก่อนเสนอ** — `SESSION-STATE.md` + บันทึกล่าสุด แล้วสรุปว่าอะไรพิสูจน์แล้ว
   อะไรเป็นสมมติฐาน อะไรถูกยกเลิกไปแล้ว
2. **แยกแยะให้ชัด:** ข้อเท็จจริงที่ยืนยันแล้ว / สมมติฐาน / แนวคิดที่ถูกตัดทิ้ง
3. **ทดลองใน shadow/dry-run เสมอ** — อย่าปรับระบบจริงก่อนมีหลักฐาน
4. **เก็บผลลบไว้** — ผลที่ล้มเหลวมีค่าเท่าผลที่สำเร็จ ห้ามลบ
5. **อย่าใช้ backtest ครั้งเดียวเป็นข้อพิสูจน์** — ต้องมีหลายช่วงเวลา/หลายสภาวะ
6. **คำแนะนำต้องผ่านประตูทดสอบ** ก่อนถูก apply
7. **อย่าประดิษฐ์ข้อมูล** — แท่งหายให้คืน `None`/โยน error ห้ามเติมแท่งเทียม

## 4) แนวทางวิจัยที่ต่อยอดได้ (ไม่ใช่คำสัญญา)

- **ปรับสไตล์ของคุณเอง** — น้ำหนักกลยุทธ์, แถบคะแนน, ระยะ SL/TP, กรอบความเสี่ยง
- **ทดสอบกรอบเวลา** — ระบบใช้ M1 เป็นตัวกระตุ้น + M5/M15/H1 ยืนยัน ลองสลับได้
- **ทดสอบกับ symbol อื่น** — เปลี่ยน `symbol` และตรวจ `digits`/`point`/`tick_value` ใหม่
- **เทียบเส้นทาง** — เทอร์มินัล MT5 ตรง vs สะพาน MetaAPI (ควรได้คำตัดสินเดียวกัน)
- **วัดผลอย่างเป็นธรรม** — เทียบช่วงเวลาเดียวกัน เงื่อนไขเดียวกัน และเก็บผลลบไว้ด้วย

## 5) การเขียนวิจัยกลับเข้าคลัง

- บันทึกเชิงหัวข้อ: `research/YYYY-MM-DD-*.md`
- บันทึกรายวัน: `research/daily/YYYY-MM-DD.md`
- เก็บเครดิตผู้สร้างไว้เสมอ
- ระบุให้ชัดว่าอะไรคือข้อเท็จจริง อะไรคือสมมติฐาน

## 6) ความซื่อสัตย์ในงานวิจัย

- **ไม่มีการรับประกันกำไร** — backtest และแบบจำลองเป็น "หลักฐาน" ไม่ใช่ "คำสัญญา"
- อย่านำ backtest ที่ผ่านครั้งเดียวมาอ้างว่าทำกำไรได้
- ข้อความ "เทรดในไทยมีกฎหมายรองรับ 100%" เป็น **นิยามที่เจ้าของระบบกำหนด**
  ไม่ใช่คำรับรองทางกฎหมายจากผู้สร้างหรือหน่วยงานใด
- XAUUSD ของโบรกเกอร์ต่างประเทศ **ไม่ใช่** สินค้าเดียวกันกับ Gold Futures ใน TFEX โดยอัตโนมัติ
