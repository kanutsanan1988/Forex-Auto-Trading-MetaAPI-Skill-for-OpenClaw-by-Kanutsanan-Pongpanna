# Research — ทำวิจัยต่อยอด

## 1) คลังงานวิจัยที่ให้มาทั้งหมด

`trading-system/research/` เก็บ **ทุกไฟล์ ทุกช่วงเวลา** ของงานวิจัยเดิม รวมถึง
ประวัติการพัฒนา บันทึกการทดลอง แผนงาน แบบจำลอง และผลทดสอบที่ล้มเหลว

**จุดเริ่มอ่าน:**

| ไฟล์ | อ่านเพื่อ |
|---|---|
| `research/README.md` | ภาพรวมคลัง |
| `research/SESSION-STATE.md` | สถานะงานวิจัยล่าสุด (สำคัญสุด) |
| `research/collaboration-history.md` | ประวัติการร่วมงาน/การตัดสินใจ |

| `research/ประวัติการพัฒนา-สารบัญ.md` | สารบัญประวัติการพัฒนา |

## 2) วิธีทำงานวิจัยกับ AI (ทำตามนี้)

1. **อ่านก่อนเสนอ** — `SESSION-STATE.md` + บันทึกล่าสุด แล้วสรุปว่าอะไรพิสูจน์แล้ว
   อะไรเป็นสมมติฐาน อะไรถูกยกเลิกไปแล้ว
2. **แยกแยะให้ชัด:** ข้อเท็จจริงที่ยืนยันแล้ว / สมมติฐาน / แนวคิดที่ถูกตัดทิ้ง
3. **ทดลองใน shadow/dry-run เสมอ** — อย่าปรับระบบจริงก่อนมีหลักฐาน
4. **เก็บผลลบไว้** — ผลที่ล้มเหลวมีค่าเท่าผลที่สำเร็จ ห้ามลบ
5. **อย่าใช้ backtest ครั้งเดียวเป็นข้อพิสูจน์** — ต้องมีหลายช่วงเวลา/หลายสภาวะ
6. **คำแนะนำต้องผ่านประตูทดสอบ** ก่อนถูก apply

## 4) กติกาความซื่อสัตย์ในงานวิจัย

- **ห้ามสร้างข้อมูลปลอม** — ถ้าแท่งไม่พอ ให้ raise หรือคืน `None` ห้ามเติมแท่งเทียม
- **ห้ามสัญญากำไร** จากผลทดลองใด ๆ
- รายงานทั้งผลสำเร็จและผลล้มเหลวเสมอ
- ระบุช่วงเวลาที่ทดลองและสภาวะตลาดที่ทดลองด้วย
- ถ้าข้อมูลขัดแย้งกัน ให้รายงานว่าขัดแย้ง — อย่าเลือกข้างที่สวยกว่า

## 5) เส้นทางพัฒนาต่อที่แนะนำ

1. ทำความเข้าใจ 12 คะแนนและแถบเกณฑ์ให้ครบก่อน (`references/architecture.md`)
2. ไล่ดูบันทึกวิจัยเก่าเพื่อรู้ว่าเคยลองอะไรแล้วล้มเหลว
3. ตั้งสมมติฐานใหม่ → ทดลองใน shadow → เก็บผล → สรุป
4. ถ้าผลดีจริง → ผ่านประตูทดสอบ → apply ในกรอบที่อนุญาต
5. บันทึกทุกอย่างกลับเข้าคลังงานวิจัย (เพื่อให้ผู้ใช้คนถัดไปต่อยอดได้)
